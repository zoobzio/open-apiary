The first pass of open-apiary: the `apiary` endpoint builder and the `Service` base class, the `makeApiary` runtime with its registry, container, and `invoke`, the `apiary build` kit that scans a source directory and writes the bundle and the OpenAPI document, the testing mocks, and the Nuxt module that mounts a bundle with `/openapi.json`, `/docs`, and a delegate.
