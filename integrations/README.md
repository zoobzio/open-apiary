# Integrations

The packages in this folder connect open-apiary to host frameworks. The runtime of each integration uses the public [`open-apiary`](../packages/open-apiary) package. The Nuxt module runs the build kit, [`@open-apiary/kit`](../packages/kit), at build time.

| Integration                   | Directory           | Description                     |
| ----------------------------- | ------------------- | ------------------------------- |
| [`@open-apiary/nuxt`](./nuxt) | `integrations/nuxt` | Adds open-apiary to a Nuxt app. |
