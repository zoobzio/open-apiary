# Integrations

The packages in this folder connect open-apiary to host frameworks. The runtime of each integration uses the public [`open-apiary`](../packages/open-apiary) package.

| Integration                   | Directory           | Description                                                                   |
| ----------------------------- | ------------------- | ----------------------------------------------------------------------------- |
| [`@open-apiary/nuxt`](./nuxt) | `integrations/nuxt` | Mounts a bundle under a base path, with the OpenAPI document and Scalar docs. |
